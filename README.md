# TKGame — платформа браузерных игр

Первая играбельная реконструкция детективной игры **«Лишний в списке»**.

**Важно:** восстановить исходники ранее опубликованного сайта `mir-raskola-lishniy-v-spiske.jazzywren11.chatgpt.site` автоматически не удалось. Эта версия создана заново по согласованным требованиям, а не получена побайтовым экспортом старой публикации.

## Что реализовано

- Четыре исследуемых локации с авторскими SVG-сценами и интерактивными объектами.
- Доступ к локациям и свидетелям по найденным знаниям, а не из открытого с начала списка.
- Инвентарь с применением предметов к объектам на сцене.
- Три головоломки (электрические каналы, кодовый замок, анализ проб).
- Показания свидетелей, журнал, карта, 14 фактов и пять цепочек доказательств.
- Проверка заключения с двумя различными финалами.
- Автосохранение в браузере. Работа без сервера и аккаунта.

## Запуск

Откройте `site/index.html` в браузере. Для хостинга укажите каталог `site/` как корень статического сайта. Отсутствуют внешние зависимости.

Для GitHub Pages настройте **Settings → Pages → Build and deployment → GitHub Actions**. Рабочий процесс `.github/workflows/deploy-pages.yml` автоматически публикует `site/` при изменениях в `main`.

Ожидаемый адрес после успешного деплоя: https://bunkovde-lab.github.io/TKGame/

## QA

`python tests/smoke.py` — сценарий полного прохождения в headless Chromium с Playwright; тест содержит изолированную загрузку ресурсов для окружений с заблокированными локальными URL. По необходимости измените `executable_path` на путь к вашему Chromium.

## Следующие задачи

Рисованная графика на уровне отдельных сцен, расширение диалогов и ветвления, визуальный граф улик, звуки, более глубокие мини-игры, интеграция с общей платформой, межбраузерные тесты.
## Новый пролог «Приказ»

Откройте `site/prologue/index.html` или выберите «Пролог» на стартовом экране. Этот эпизод охватывает вводную, подготовку на шаттле и стыковку. Предыдущая тестовая реконструкция открывается по исходному адресу.

`node tests/prologue.mjs` проверяет правила пролога, прохождение и восстановление состояния.
