# TKGame — платформа браузерных игр

Репозиторий для исходного кода браузерной игровой платформы и отдельных игр.

## Первая игра: «Лишний в списке»

Детективное расследование от первого лица: исследование локаций, поиск и сопоставление улик, инвентарь, карта, диалоги, проверки и заключения. Доступ к персонажам и локациям должен зависеть от знаний игрока, а не от перебора всех ответов.

**Текущая опубликованная версия:** https://mir-raskola-lishniy-v-spiske.jazzywren11.chatgpt.site

**Статус импорта (4 ноября 2026):** существующий сайт опубликован отдельно; его исходные файлы ещё не были экспортированы в этот репозиторий. Наличие ссылки на игру НЕ означает, что её код находится здесь. Не подменять исходный проект незавершённым прототипом.

## Подключение исходников

1. Экспортировать **исходный проект** текущей опубликованной игры (файлы HTML/CSS/JS/TS, ассеты, сценарные данные, конфигурацию сборки), а не одни лишь скриншоты или ссылку.
2. Перенести в этот репозиторий, сохранив структуру и пути ресурсов. Для статической HTML-игры допустимы `site/index.html` и `site/assets/`. Для React/Vite — `index.html`, `src/`, `public/`, `package.json` и lock-файл.
3. Проверить сборку, маршруты, медиа, сохранение прогресса и работу на планшете.
4. В Settings → Pages установить **Build and deployment → GitHub Actions** (может потребоваться включение GitHub Pages).
5. Отправка исходников в ветку `main` запустит workflow `.github/workflows/deploy-pages.yml`. Планируемый адрес после успешной публикации: https://bunkovde-lab.github.io/TKGame/

## Рекомендуемая структура (после импорта)

```text
TKGame/
├── index.html                # либо site/index.html для статической сборки
├── src/                      # логика платформы и игры при использовании сборщика
├── public/                   # изображения, звуки, шрифты и сценарные данные
├── games/                    # будущие игры каталога
└── .github/workflows/
    └── deploy-pages.yml
```

Пока исходники текущей игры не перенесены, GitHub Pages **не является** проверенной играбельной сборкой. Ссылка выше ведёт на первоначально опубликованную версию игры.
