# Бюро — платформа детективных игр

Браузерная платформа «Бюро» и первое дело для семьи — **«Синяя птица»** (1,5–2,5 часа, 1–6 игроков за одним экраном, 12+).

## Как запустить

Сборка не нужна, это статический сайт на чистом HTML/CSS/JS.

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Один файл для офлайн-игры: `python3 tools/build_single.py` соберёт `dist/bureau.html`, его можно открыть двойным щелчком.

## Что внутри

- **Платформа:** главная, каталог дел (одно доступно, три анонса), профиль семьи со значками участников, шкафом раскрытых дел и достижениями. Всё хранится в `localStorage`, сервер не нужен.
- **Дело «Синяя птица»:** вымышленная кража картины по мотивам кражи «Моны Лизы» (1911) и «Зелёного свода» (2019). Три акта, 15 мини-механик: осмотр места с зумом, допросы с противоречиями, записи камер, свидетель по памяти, телефон свидетеля, найди отличия, база данных со свободным вводом, лаборатория (отпечатки и ткани), хронология, таблица алиби, шифр Цезаря, карта с бюджетом времени, доска улик, тайное семейное голосование, реконструкция и обвинение с частичным зачётом.
- Диздок дела: [`docs/design/case-01-blue-bird.md`](docs/design/case-01-blue-bird.md).

## Структура

```
index.html                 оболочка
css/bureau.css             стили
js/store.js                профиль и сохранения (localStorage)
js/platform.js             главная, каталог, профиль, маршруты (#home, #catalog, #profile, #play)
js/case-bluebird/data.js   весь контент дела: улики, допросы, локации, ответы
js/case-bluebird/art.js    иллюстрации (SVG кодом)
js/case-bluebird/game.js   движок дела и мини-механики
tests/playthrough.js       полное прохождение в Playwright (десктоп и телефон)
```

## Тест

```bash
python3 -m http.server 8765 &
node tests/playthrough.js            # десктоп 1366×860
W=390 H=844 node tests/playthrough.js # телефон
```

Скрипт проходит дело целиком, проверяет улики и итоговый счёт, ловит ошибки консоли и горизонтальную прокрутку.
