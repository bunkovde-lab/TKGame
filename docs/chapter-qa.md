# Проверка главы «Семь имён»

## Автоматические контрольные прохождения

Команды: `node tests/chapter.mjs`, `node tests/chapter-ui.mjs`, `node tests/prologue.mjs`.

| Ситуация | Ожидаемое поведение | Проверенный результат |
|---|---|---|
| Нажать все доступные реплики без экспертиз | Обоснованный финал недоступен | PASS: показаний недостаточно для завершения |
| Отказаться от показаний Миры | Сохранить независимый путь по предметам и документам | PASS: полный путь без тем Миры |
| Ошибка в каждой из четырёх экспертиз | Потеря времени, новая подготовка перед повтором | PASS: повтор блокируется, повторный отбор восстанавливает возможность |
| Неверная комбинация улик | Вывод не подтверждён, та же комбинация повторно не принимается | PASS |
| Недостаточный пакет для Центра | Отказ с указанием недостающих оснований | PASS: дополнение позволяет получить санкцию |
| Несанкционированное давление на Восса | Ложное признание не становится доказанным раскрытием | PASS |
| Отказаться от обоих конфликтов | Аналитическое расследование остаётся проходимым | PASS |
| Силовой план с потерей носителя | Сохранить архивный альтернативный путь | PASS |
| Занята Ирена | Другая работа продолжается, результат после требуемых действий | PASS |
| Завершить дело без подтверждённого организатора | Содержательный финал блокируется | PASS |
| Загрузить сохранение во время поручения | Срок и состояние поручения сохраняются | PASS |
| Разные обоснованные решения | Три разных финала достижимы | PASS |
| Произвольное закрытие дела | Отдельное подтверждение, исход с недостаточными материалами | PASS |
| Интерфейсные панели и конструкции головоломок | Нет ошибок от несогласованных схем данных | PASS: DOM smoke; геометрию браузера не заменяет |
| Пролог после добавления перехода к главе | Стыковка и исходные ограничения работают | PASS |

## Непосредственно в браузере

Проверены начальная сцена, пагинация, мысли героя, получение разрешения семьи и квитанции, открытие новых адресов, карта с иллюстрацией станции, разговор с Мирой на фоне зала, переход на шаттл и успешная интерактивная сверка ведомостей. Найденный недостаточный контраст основной кнопки исправлен.

## Границы проверки

Длительность независимого первого прохождения пока не измерена. Цель — 1–2 часа, а не заявленный результат авторского скоростного маршрута. Физический Android-планшет и все разрешения экрана не проверены. Автотесты подтверждают достижимость предусмотренных путей, но не заменяют оценку понятности загадок живым игроком.

В этой главе расписание полноценных перемещений каждого NPC ещё не реализовано: время меняет сроки и последствия операции, не подменяется обещанием отсутствующей симуляции. Новые механики и дополнительные позы персонажей можно расширять поверх сохранённого состояния дела.
